# Bienvenido al Estudio de Diabetes

**Integrantes:** Mariana Franco, Jerónimo Domínguez, Juan Andrés Ramos

Este libro ha sido generado con Jupyter Book y tiene como objetivo presentar un análisis exploratorio de datos (EDA) sobre factores relacionados con el diagnóstico de diabetes.

Se abordan aspectos como la distribución de la enfermedad según el sexo, estado, hábitos físicos y estado de salud general, mediante gráficos y código en Python. El análisis se basa en una base de datos limpia de salud pública.

Este recurso está orientado a investigadores, estudiantes y profesionales de ciencia de datos interesados en aplicar técnicas de análisis a temas de salud pública.
